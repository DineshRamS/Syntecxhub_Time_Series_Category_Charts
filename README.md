# Syntecxhub Time Series & Category Charts

## Project Overview

This project is part of the Syntecxhub Data Science Internship Week 2 tasks.

The project analyzes shampoo sales over a three-year period using Python, Pandas, and Matplotlib.

## Analysis Performed

- Loaded and inspected the sales dataset
- Analyzed monthly sales over three years
- Created a line chart for sales over time
- Calculated average sales for each month
- Created a monthly sales bar chart
- Calculated yearly total sales
- Created a pie chart showing yearly sales share
- Aggregated sales by quarter
- Created a quarterly sales bar chart
- Added a short interpretation of the charts

## Key Results

- Number of records: 36
- Total sales: 11253.6
- Average monthly sales: 312.6
- Highest monthly sales: 682.0
- Highest sales month: 3-Sep
